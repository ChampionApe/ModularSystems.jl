# logs

Detached-run scripts and their output. Gitignored apart from this file: a log is evidence for the
session that produced it, not repository content.

The pattern for launching a run so it survives the session — and the Windows gotchas that make the
difference between a finished run and a mangled log — is in `notes/detachedRuns.md`.

One script and one log per run, named after the run. Keep the script: it is the record of what was
actually executed, at what settings.
